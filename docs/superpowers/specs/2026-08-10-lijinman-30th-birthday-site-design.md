# 李金蔓三十岁生日网站设计规格

## 1. 项目目标

为李金蔓制作一个公开访问、移动端优先的三十岁生日互动网站。网站不渲染“年龄焦虑”，而把三十岁表达为轻松进入人生下一张地图。她是故事中的杰瑞；追赶她的汤姆象征工作、疲惫和日常烦恼。追逐最终转化为陪伴与庆祝。

## 2. 已确认的创意方向

- 主题名暂定为“猫鼠三十・追光之旅”。
- 采用用户提供的视觉参考：奶油纸张质感、手账拼贴、暖黄奶酪、柔和粉橙色、圆润边角和轻松动画感。
- 回忆不按时间排序。十块奶酪分别代表十段独立回忆，每块可承载图片、短视频和文字。
- 十块奶酪全部打开后，解锁一支完整的主祝福视频。
- 主视频结束后进入新征程终章：发光的新地图/拱门开启，汤姆与杰瑞停止追逐，共同拉开“李金蔓，三十岁生日快乐！”横幅。
- 网站任何拿到链接的人都可以访问，不设置密码。

## 3. 交互方案比较与选择

### A. 单页纵向故事

像绘本一样向下滚动，逐章打开回忆。实现稳定，但探索感弱，十块奶酪容易显得重复。

### B. 人生游乐地图（采用）

首页进入一张非线性游乐地图，十个场景各藏一块奶酪。用户可以自由选择顺序，符合“回忆不按时间线”的要求，也最能体现闯关和新地图主题。

### C. 横版追逐小游戏

操作感最强，但会让操控和输赢抢走生日内容的注意力，且手机端门槛更高，因此不采用。

## 4. 页面与体验流程

### 首页：冒险启程

- 首屏标题：“30 岁的第一场冒险，由我们一起开启！”
- 展示追逐中的汤姆与杰瑞、奶酪路标和通往新地图的拱门。
- 主按钮：“开始追奶酪”。
- 页面可有轻量漂浮奶酪、脚印与纸屑动画；尊重系统减少动态效果设置。

### 奶酪地图：十段快乐奶酪

- 以一张手绘游乐地图承载十个地点，不表示年份或固定时间顺序。
- 十块奶酪均可自由打开；已看过的奶酪显示完成印章。
- 顶部显示“已收集 X / 10 块快乐奶酪”。
- 进度保存在浏览器本地，刷新后不丢失。
- 可重复进入任何回忆，不设置失败、倒计时或操作惩罚。

### 回忆详情：奶酪里的故事

- 每段回忆包含：标题、可选短文、1 个主媒体位，以及可选的 3–4 个补充图片/视频位。
- 支持图片与 MP4/WebM 视频；视频使用原生播放控制，不自动播放有声音的视频。
- 提供上一块、下一块和返回地图操作。
- 素材尚未提供时显示设计完整的相框占位，不使用工程化灰框。

### 最终祝福：第十一份惊喜

- 十块奶酪都打开后，地图中央出现一块发光的金色奶酪，按钮文案为“开启最后的惊喜”。
- 点击后进入沉浸式主视频放映页。
- 主视频播放完毕后自动解锁“迈入新地图”，同时保留手动继续按钮，避免浏览器事件或视频加载异常导致流程中断。

### 尾声：新地图开启

- 发光拱门打开，场景由追逐转为并肩庆祝。
- 汤姆和杰瑞共同展开横幅：“李金蔓，三十岁生日快乐！”
- 副文案：“新地图已开启，继续做最快乐的杰瑞。”
- 提供“再看一次回忆”按钮返回地图。

## 5. 视觉系统

- 背景：象牙白到浅奶油色，带极轻纸张颗粒。
- 主色：奶酪黄、蜂蜜橙；强调色使用珊瑚粉；文字为暖棕色。
- 组件：相纸、便签、胶带、邮戳、手绘路线、脚印；避免现代 SaaS 式卡片网格。
- 字体：标题采用有手写感但清晰的中文字体；正文采用高可读中文黑体。优先使用可合法加载的网络字体或系统字体降级。
- 动效：小幅弹跳、路线描边、相纸翻开、奶酪收集闪光；不做高速追逐或焦虑式倒计时。
- 参考图作为视觉基准：`C:\Users\32442\Desktop\30岁生日\ChatGPT Image 2026年8月10日 19_49_18.png`。

## 6. 内容配置

十段回忆与主视频都从一个集中配置文件读取，便于后续只替换标题、文案和媒体路径而不改页面代码。初始版本提供十组清晰命名的占位素材目录和字段说明。

## 7. 技术架构

- 使用 React、TypeScript 与 Vite 构建纯前端网站。
- 使用 CSS 动画和少量状态管理实现交互，不引入后端数据库。
- 访问进度使用 `localStorage` 保存；存储失败时退化为当前会话内状态。
- 本地开发完成并经用户确认后，再创建 GitHub 远程仓库并部署到 Cloudflare。
- 静态站点优先部署到 Cloudflare Pages；实际视频体积确认后再决定随站点发布或改用 Cloudflare R2/Stream，避免大文件影响构建与访问。

## 8. 响应式与无障碍

- 手机端是主要体验，地图改为可自然纵向浏览的路线，不依赖精确点击或悬停。
- 桌面端展示完整游乐地图与更丰富的场景空间。
- 所有交互支持键盘操作、清晰焦点状态和媒体替代文本。
- 颜色对比、字号、触控目标符合基本可访问性要求。

## 9. 异常处理

- 单个图片或短视频加载失败时显示对应回忆的备用相框与提示，不影响奶酪收集。
- 主视频加载失败时提供重试和跳过到生日终章的入口。
- 用户可随时返回地图，最终关卡一旦解锁便保持可访问。

## 10. 验收标准

- 十块奶酪可按任意顺序打开，进度显示和本地保存正确。
- 每个回忆媒体位可用真实图片或视频直接替换。
- 十段回忆完成后才能首次解锁主视频与尾声。
- 主视频完成或手动继续后能进入横幅终章。
- 桌面端与常见手机宽度无横向溢出、文字遮挡或不可点击区域。
- 最终实现与参考图在色彩、排版气质、纸张拼贴和猫鼠冒险氛围上保持一致。

## 11. 范围边界

首版不包含账号、密码、评论、素材后台、访客上传、在线数据库或复杂游戏物理。素材替换通过项目内配置与文件完成。GitHub 发布和 Cloudflare 部署将在本地版本获得用户确认后进行。
